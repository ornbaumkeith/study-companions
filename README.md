## Use

1. Download the HTML file for your certification.
2. Open it in a modern desktop browser. Core study features work offline.
3. Use the built-in navigation, flashcards, and practice questions. Official documentation links require internet access.
4. Where available, export your progress before switching browsers or devices. Progress is stored locally in the browser.

## Files

- `downloads/` contains the four complete HTML companions. Existing distribution filenames are retained.
- `screenshots/` contains the original dashboard images used by the portfolio website, plus their upload helper. These historical screenshots are preserved as supplied.

The companions and original screenshots were moved from `ornbaumkeith/ornbaumkeith.github.io/assets/study-companions` on October 26, 2026. The HTML files include the neutral light/dark color update and Study Companions branding. Study content and application logic are unchanged.

## Independent study material

These are independently authored study aids, not official Esri training or actual certification exam questions. They are not affiliated with or endorsed by Esri. Consult Esri documentation and current exam guidance alongside your study.
